📖 What Is manga-cli?

manga-cli is a small, fast program that lets you read manga without opening a browser. You type a title, pick a chapter, and the pages open in a viewer window. That is the whole idea. No accounts, no sign-ups, no cluttered pages full of banners.

It is inspired by a popular tool called ani-cli, which does the same thing for anime. If you have ever wished manga reading could be as simple as typing a name and pressing Enter, this is exactly that.

The program is powered by mpv, a well-known media player, and it pulls content from several manga sources. If one source is slow or unavailable, manga-cli quietly switches to another one so you can keep reading. It also remembers where you stopped, so you never lose your place.

✨ Key Features

  • Lightweight and quick. The program is tiny and starts almost instantly, so there is no waiting around.
  • Terminal-first design. Everything happens in one window. Search, choose, read, close.
  • Multiple sources. manga-cli knows several manga libraries and searches them for you.
  • Automatic fallback. If a source stops responding, the app moves to the next one on its own.
  • Persistent progress. Your current chapter and page are saved between sessions.
  • Customizable themes. Change the colours of the interface to suit your eyes and your mood.
  • Open source. The code is public, free to use, and free to improve.

🚀 Getting Started

The steps below are written for someone who has never used a terminal before. Follow them in order and you will be reading in a few minutes.

Step 1 — Open the download page

Open your web browser and go to the releases page using the button above. Every version of manga-cli that has ever been published is listed there, with the newest one at the top.

Step 2 — Pick the newest release

Look for the entry marked as the latest release. Click it to expand the list of files attached to that version. You do not need an account, and nothing will be posted on your behalf.

Step 3 — Download the file

Click the file name to download it. Your browser will save it in your Downloads folder, which you can open from the folder icon in your taskbar or from File Explorer.

Step 4 — Run the application

manga-cli is a terminal program, so it runs inside a command window rather than by double-clicking an icon. On Windows, open Terminal from the Start menu (search for “Terminal” or “Command Prompt”). Navigate to the folder where you saved the file, then start manga-cli by typing its name and pressing Enter.

Step 5 — Read your first manga

Once the program is running, type the name of a manga you want to read and press Enter. A list of matching results appears. Choose one with the arrow keys, press Enter, and then choose a chapter. The pages will open in a viewer window and you can start reading right away.

🎮 Using manga-cli Day to Day

After the first session, the routine becomes very short. Open your terminal, start manga-cli, search a title, and continue where you left off. The app keeps a record of the chapter and page you last reached, so the next time you open the same series it will offer to resume.

Navigation is handled with the arrow keys and the Enter key. To go back a step, press Escape. To close the reading window and return to the terminal, simply close the viewer.

Because everything happens in text, the app stays fast even on older machines. There are no ads, no pop-ups, and no background downloads running while you read.

🎨 Themes and Customization

manga-cli ships with a set of ready-made themes, so you can switch between a bright daytime look, a soft dark look, and a few colour variations without editing anything complicated. Themes change the colours of the menus and the text, which makes long reading sessions easier on the eyes.

If you enjoy tinkering, the theme files are simple and readable, and you can copy one, adjust the colours, and save it as your own. Your selection is remembered the next time you open the app.

💾 Persistent Progress Explained

Every time you finish a chapter or close the reader, manga-cli writes down where you stopped. That note is stored locally on your own computer. Nothing is uploaded anywhere, and no personal reading history leaves your machine.

This means you can close the terminal, shut down, and come back days later. Open the same manga and the app will point you to the correct chapter and page.

🌐 Multiple Sources and Automatic Fallback

Websites go down, change their layout, or slow to a crawl. manga-cli expects this. It searches more than one manga source at once and, if your first choice stops working, it silently tries the next one.

In practice you rarely notice this happening. You ask for a chapter, and a chapter opens. The fallback is there so a single broken website never blocks your reading.

🛠️ Troubleshooting

The terminal says the command is not recognised. This usually means the terminal is looking in the wrong folder. Double-check that you are in the folder where the downloaded file lives, then try again.

Pages do not appear. The most common cause is a source being temporarily unavailable. Wait a minute and search again; the fallback system will usually find a working source.

The viewer window closes straight away. Close the terminal completely, reopen it, and start the app again. A fresh start clears most temporary hiccups.

Text looks garbled or misaligned. Widen the terminal window. Very narrow windows can break the layout of the menus.
